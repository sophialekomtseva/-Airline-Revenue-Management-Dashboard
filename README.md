Аналитический BI-дашборд для коммерческого директора авиакомпании. Проект демонстрирует полный цикл работы BI-аналитика: от проектирования модели данных в PostgreSQL до интерактивной визуализации в Tableau.
Контекст и цель проекта
Авиакомпании ежедневно генерируют сотни тысяч записей о бронированиях, рейсах и пассажирах. Без правильной аналитической инфраструктуры эти данные остаются «сырыми» и не используются для стратегических решений.
Цель проекта — трансформировать операционные данные в инструмент поддержки бизнес-решений: анализ динамики выручки, выявление топ-направлений, оценка эффективности маршрутов.
Бизнес-вопросы

Дашборд отвечает на ключевые вопросы коммерческого директора:

1. Какова динамика выручки и количества проданных билетов по месяцам?
2. Какие 10 направлений приносят максимальную выручку?
3. Как меняется доля бизнес-класса в общей выручке во времени?
4. Какие маршруты наиболее эффективны (соотношение объёма и среднего чека)?
5. Как отличается средний чек в зависимости от дня недели вылета?
6. Какие направления являются кандидатами на оптимизацию или отмену?

Модель данных
Применена модель Star Schema — стандарт индустрии для BI-систем:

- fact_bookings_enriched — центральная таблица фактов (билеты, рейсы, выручка)
- dim_airports — справочник аэропортов (города, названия)
- dim_date — календарь на 10 лет (год, месяц, квартал, сезон, день недели)
- dim_aircrafts — справочник самолётов (модель, дальность)
- dim_flights — справочник рейсов

Ключевые инсайты
- Топ-3 направления (Москва ↔ Новосибирск, Москва ↔ Хабаровск) генерируют ~40% всей выручки
- Доля бизнес-класса составляет около 30%, но сильно варьируется по направлениям (от 15% до 35%)
- Средний чек максимален в выходные дни (суббота, воскресенье) — сигнал для тарифной политики
- Scatter-анализ выявляет маршруты с высоким трафиком, но низкой маржой — кандидаты на пересмотр
